# 图书编校差错示例分析 (2022-2026)

清华大学出版社质量管理中心发布的图书编校差错示例分析汇总。

## 数据来源

- 16 个季度报告（2022 Q1 - 2026 Q2）
- 共计 **752 条**典型错例
- 来源：成品图书质检、印前清样质检、读者反馈

## 分类

- **文科类**：表述不准确、成语误用、引文差错、标点符号差错等
- **理工类**：知识性差错、数值差错、术语差错、符号差错等
- **外语类**：语法差错、文字差错、翻译差错等
- **读者反馈**：读者来函/热线反馈的各类差错

## 本地运行

直接在浏览器中打开 `index.html` 即可，无需服务器。
